## About the Project

Bits and Quirks is a compact Vanilla+ Minecraft project made with the Fabric modding platform. It provides room to try out custom Minecraft content while preserving an overall feel that remains close to the vanilla game.

The project doubles as a hands-on Java learning exercise. Its development covers the organization of a Minecraft mod, Fabric integration, and the creation of new content without turning the experience into something entirely separate from the base game.

## Installation

1. Get the newest build using the download link above.
2. Check that the build's required Minecraft and Fabric Loader versions are being used.
3. Install Fabric Loader for Minecraft Java Edition.
4. Copy the Bits and Quirks `.jar` file into the instance's `mods` directory.
5. Launch the Fabric profile. If the mod fails to load, inspect the game log for details.

The mod file should typically be placed as follows:

```text
.minecraft/
└── mods/
    └── bits-and-quirks.jar
```

When testing changes or builds created locally, use a dedicated test instance.
